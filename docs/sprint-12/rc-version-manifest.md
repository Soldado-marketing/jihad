# Sprint 12 RC Version Manifest

## Purpose

Define the release candidate manifest for Sprint 12 stabilization.

| Field | Value |
|---|---|
| Product | MAOS MVP |
| Release candidate | RC-0.1.0 |
| Sprint | Sprint 12 |
| Date | 2026-06-01 |
| Scope | MVP release candidate stabilization and performance readiness |
| Source status | Sprint 1 through Sprint 11 complete |
| Production launch status | Not launched |
| Migration status | No production migration created in Sprint 12 |
| External provider status | Deferred/inactive |
| Performance target | 50 concurrent users baseline readiness |
| Future scaling path | 100, 250, 500 concurrent users |

## Included MVP Areas

- Identity, tenants, sessions, devices, login history.
- RBAC, permission guard foundation, audit baseline.
- Workspace shell and navigation.
- Projects, tasks, subtasks.
- Client portal foundation.
- CRM basic and collaboration foundation.
- Files, file versioning, approvals.
- Chat, notifications, realtime placeholders.
- Voice notes and voice-to-task basic placeholders.
- Finance basic.
- Dashboards and reports basic.
- QA, UAT, security hardening, release readiness.

## Excluded / Deferred

- Advanced BI, forecasting, anomaly detection.
- Report export, scheduled reports, custom report builder.
- Automations and payroll automation.
- Advanced wallet system.
- Real AI/transcription/payment/storage/realtime provider integrations.
