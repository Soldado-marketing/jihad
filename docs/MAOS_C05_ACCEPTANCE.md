## Scope notes

- "MinIO" in the task note is replaced by the in-memory S3 stub (MinIO downloads and images are archived; recorded in A09). The stub implements `Range` the way S3 does (`206`, `Content-Range`), which is what the API's SDK path exercises.
- Production verification above 25 MiB depends on O6 (production `FILE_MAX_UPLOAD_BYTES`), an owner environment change outside this task. Recorded, not reduced.
- Browser playback uses a blob object URL (the bearer token cannot ride on a `<video src>`), so the first frame waits for the whole download; the API now honours ranges, which makes a direct streaming player possible once a short-lived capability URL is approved (Blueprint §6.11 "signed URLs"). Not part of C05's criteria; recorded as the next improvement.
- Range requests on the client route read the whole object from storage once and discard what lies outside the window (the metadata boxes must be located from the start of the file); the response itself is exact. Browsers never issue them today (blob playback).
