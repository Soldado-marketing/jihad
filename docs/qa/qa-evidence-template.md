# MAOS QA Evidence Template

## Purpose

Define the QA evidence structure required for Sprint 1 and later acceptance validation.

## Evidence Record

| Field | Required | Description |
|---|---:|---|
| Evidence ID | Yes | Unique evidence reference |
| Test Case ID | Yes | Linked test case or task |
| Tester | Yes | Tester name or role |
| Environment | Yes | Local, QA, staging, UAT, or production |
| Role | Yes | Owner, Manager, Employee, Client, or system role |
| Tenant | Yes | Tenant used during test |
| Client/Project Scope | Yes | Client, project, task, or resource scope tested |
| Expected Result | Yes | Expected outcome |
| Actual Result | Yes | Observed outcome |
| Permission Result | Yes | Allowed, denied, redacted, suppressed, or not applicable |
| Logs/Screenshots References | Yes | Link or reference to supporting evidence |
| Pass/Fail | Yes | Final test result |
| Reviewer | Yes | Reviewer role or person |
| Timestamp | Yes | Evidence capture time |
