# MAOS Transcription Provider Shortlist

## Transcription Provider Options

| Option | Notes |
|---|---|
| AI provider transcription API | Operationally simple if language quality and retention terms pass |
| Specialist transcription provider | May improve language quality; security and integration review required |
| Manual transcript fallback | Required fallback for failed or low-confidence transcription |

## Arabic Benchmark Requirement

Provider must be tested with Arabic voice samples including agency/task vocabulary, varying accents where practical, and RTL transcript display expectations.

## English Benchmark Requirement

Provider must be tested with English project/task/client workflow language.

## German Benchmark Requirement

Provider must be tested with German voice samples, longer words, and agency-specific vocabulary.

## Mixed-Language Benchmark

Provider must be tested with mixed Arabic/English/German phrases and names common in distributed agency work.

## Owner

AI Systems Architect.

## Assigned Sprint 8 Gate

Transcription provider must be approved before voice-to-task implementation exits Sprint 8.
