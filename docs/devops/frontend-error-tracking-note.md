# MAOS Frontend Error Tracking Note

## Error Tracking Placeholder

Frontend error tracking is required before MVP launch and should be selected before frontend implementation matures beyond core shell/navigation work.

## Privacy Expectations

Error tracking must not capture secrets, full request bodies, file content, chat content, voice transcripts, payment details, payroll data, or sensitive client data.

## Environment Dependency

Telemetry must separate local, QA, staging, UAT, and production events. Production error tracking requires approved secrets/config handling.

## Owner

Frontend Lead / DevOps Architect.

## Assigned Gate

Sprint 2 frontend shell readiness or earlier if frontend errors need shared visibility.

## Acceptance Criteria

| Criterion | Status |

| Privacy expectations are documented | Met |
| Environment dependency is documented | Met |
